# Calculadora de Consumo de Água 💧

Uma calculadora simples e interativa que permite estimar o **consumo diário de água** com base em hábitos domésticos, como banho, uso de torneira e máquina de lavar. Ideal para conscientização sobre economia de água! 🌱

## Funcionalidades

- Cálculo do consumo diário de água.
- Entrada de dados personalizável: número de banhos, usos de torneira e lavagens de roupa.
- Resultado em litros, de forma clara e visual.

## Tecnologias Utilizadas

- **HTML5**: Estrutura da página.
- **CSS3**: Estilo e layout responsivo.
- **JavaScript**: Lógica de cálculo e interatividade.
